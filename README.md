# Golf Practice Coach PWA v5

## v5 changes
- 履歴を展開してクラブ別集計・距離・1球ごとの記録を表示（旧版は保存済みレポートを表示）
- 飛距離スライダー（0〜400yd）、±1yd調整、平均に戻す、距離不明
- キャリーとラン込みを分けて保存・集計
- クラブごとの直近300球から、距離を記録した球だけの平均を入力基準に使用
- データがない場合は初期値100yd・距離不明。スライダー調整時に距離記録を有効化
- 飛距離ページ：日ごとの直近300球移動平均、日別数値、全記録/直近300球の最大、標準偏差
- 保存前の記録も集計。現在の練習はセッションIDで保存を更新し、同じ球の二重集計を防止
- 全記録のJSONバックアップ出力（この版に復元UIはなし）
- 旧記録に飛距離を推測して補完しない。距離不明や別距離種別は平均から除外。0ydとミスは含む

## v4 changes
- 記録ボタン12個を3列×4行ですべて表示
- 記録欄内のスクロールとスナップを廃止

## v3 changes
- クラブ別の記録球数を集計欄で強調表示
- 選択中のクラブとそのクラブの記録球数を記録ボタンの上に大きく表示
- ショット記録に「シャンク」を追加（集計とChatGPT用レポートにも反映）
- 記録ボタンを大きくし、1画面に2つずつ表示するスクロール領域と軽いスナップを追加
- 既存の記録とクラブ設定はそのまま引き継ぎ

## v2 changes
- 100球固定を廃止
- 目標球数を自由設定（1〜999球）
- 50 / 80 / 100 / 120 / 150球のクイック設定
- 使用クラブを自由に追加・削除
- 使用クラブの並び替え
- 既存の練習ログは維持
- 過去に使用したクラブは削除後も集計データに残る
- ChatGPTレポートが設定球数に追従

GitHub の既存リポジトリで `index.html`、`sw.js`、`README.md` を更新すれば自動デプロイされます。
