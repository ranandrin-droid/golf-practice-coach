# Golf Practice Coach PWA v7

## v7 changes
- クラブ設定で飛距離入力の上限を個別設定（1〜300yd、初期値300yd）
- クラブ選択に合わせてスライダー上限・目盛り・±1yd調整・平均入力値を切り替え
- 平均が上限を超える場合は入力だけを上限に合わせ、過去の距離や平均は保持
- 履歴の距離編集にもクラブ別上限を適用。既存の上限超の距離は変更しない限り保持
- 上限設定は端末に保存し、JSONバックアップにも含む。削除したクラブを同名で再追加すると設定を再利用

## v6 changes
- 新規飛距離の入力上限を300ydに変更。既存の300yd超の記録は保持
- スライダーに50yd刻みの目盛りと数値ラベルを追加（調整単位は1ydのまま）
- 履歴を個別に編集：練習日・目標・メモ、クラブ・打球結果・距離種別・飛距離・球の除外
- 旧履歴は練習日・目標・メモと保存済みレポートを編集可能
- 編集後に集計・推移・レポートを再計算。現在の練習に対応する履歴の編集は現在の記録にも反映
- 個別/全履歴削除は削除済みに移動。削除済みの履歴は集計対象外、復元可能（現在の練習は別途残る）

## v5 changes
- 履歴を展開してクラブ別集計・距離・1球ごとの記録を表示（旧版は保存済みレポートを表示）
- 飛距離スライダー（0〜400yd）、±1yd調整、平均に戻す、距離不明
- キャリーとラン込みを分けて保存・集計
- クラブごとの直近300球から、距離を記録した球だけの平均を入力基準に使用
- データがない場合は初期値100yd・距離不明。スライダー調整時に距離記録を有効化
- 飛距離ページ：日ごとの直近300球移動平均、日別数値、全記録/直近300球の最大、標準偏差
- 保存前の記録も集計。現在の練習はセッションIDで保存を更新し、同じ球の二重集計を防止
- 全記録のJSONバックアップ出力（この版に復元UIはなし）
- 旧記録に飛距離を推測して補完しない。距離不明や別距離種別は平均から除外。0ydとミスは含む

## v4 changes
- 記録ボタン12個を3列×4行ですべて表示
- 記録欄内のスクロールとスナップを廃止

## v3 changes
- クラブ別の記録球数を集計欄で強調表示
- 選択中のクラブとそのクラブの記録球数を記録ボタンの上に大きく表示
- ショット記録に「シャンク」を追加（集計とChatGPT用レポートにも反映）
- 記録ボタンを大きくし、1画面に2つずつ表示するスクロール領域と軽いスナップを追加
- 既存の記録とクラブ設定はそのまま引き継ぎ

## v2 changes
- 100球固定を廃止
- 目標球数を自由設定（1〜999球）
- 50 / 80 / 100 / 120 / 150球のクイック設定
- 使用クラブを自由に追加・削除
- 使用クラブの並び替え
- 既存の練習ログは維持
- 過去に使用したクラブは削除後も集計データに残る
- ChatGPTレポートが設定球数に追従

GitHub の既存リポジトリで `index.html`、`sw.js`、`README.md` を更新すれば自動デプロイされます。
